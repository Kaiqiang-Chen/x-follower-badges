# X 粉丝数 · Follower Badges

在 X 时间线的作者昵称旁显示粉丝数，并提供关注、取关及互关状态。Chrome Manifest V3 扩展，当前版本 **1.1.3**。

## 功能

- 粉丝数：支持简洁和完整数字，悬停查看完整数值。
- **＋关注**：通过当前作者的 X 原生菜单关注，无需进入个人主页。
- **已关注**：点击取消关注，执行前弹出确认框。
- **互关**：只有页面数据明确显示双方都关注时才显示，支持点击取关。
- **已申请**：显示私密账号的待批准状态。
- 独立开关：粉丝数和快捷关注可分别关闭。
- 适配动态时间线、重复作者和帖子容器复用；一次只处理一个操作。

## 安装

1. 下载仓库 ZIP 并解压，或克隆仓库。
2. Chrome 打开 `chrome://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择仓库中的 **`extension/` 文件夹**。
4. 刷新 X 页面。

保留插件文件夹。更新代码后，先在扩展管理页点击本扩展的重新加载，再刷新所有需要使用的 X 标签页。不要同时启用多个副本。

## 数据和权限

仅申请 `storage` 权限，用于保存显示设置；内容脚本只在 `x.com`、`twitter.com` 及其 `www` 域名运行。

扩展观察页面已有响应，提取粉丝数和关注关系，数据仅保存在当前页面内存。不会读取或保存登录凭证，不上传用户数据，不自行构造关注 API 请求。

关注和取关仅由用户主动点击触发，调用 X 原生菜单；取关前由扩展请求确认。成功状态来自 X 原生提示或接口回执，不自动批量操作。

## 局限与故障排查

- X 的页面结构、接口字段或菜单文案变化可能影响兼容性。
- 未返回粉丝数或关系字段时，不猜测数据。未知对方关注关系不会显示为互关。
- 支持简体中文、部分繁体中文和英文菜单；成功提示兼容性主要验证了简体中文。
- “尚未确认操作结果”表示扩展没有及时读到成功证据，不等于 X 操作失败。可用 X 原生菜单核对状态；收到新的状态后会清理过期提示。
- 原生菜单可能短暂出现。已打开的旧标签页需要刷新才能加载新版脚本。

## 开发与测试

需要 Node.js 22.12+（当前测试环境为 Node.js 24）。

```sh
npm ci
npm test
```

包含 25 项本地模拟测试，覆盖粉丝数提取与排版、关注和取关、确认与取消、互关、重复点击、账号精确匹配、容器复用、过期响应、分节点成功提示和旧错误清理。

真实登录页面已验证按钮排版、互关显示、原生菜单入口和扩展确认框。最终版本的全部关注/取关网络路径尚未完整实测；模拟测试不保证 X 后续变更后的兼容性。

## 文件结构

- `extension/manifest.json`：扩展配置。
- `extension/interceptor.js`：观察现有响应并提取粉丝数和关系。
- `extension/content.js`、`badges.css`：粉丝数标签和按钮样式。
- `extension/follow.js`：关注、取关、互关和操作状态。
- `extension/popup.*`：设置界面。
- `extension/core.js`：字段提取与格式化测试辅助模块，运行入口使用独立脚本。
- `tests/`：模拟测试。
